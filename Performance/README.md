# Performance

Dashboard de rendimiento desarrollado en Python con Tkinter.

## Ejecutar

La primera vez, guarda la cuenta de PMX Agile en Windows Credential Manager:

```powershell
python3.12 configure_pmx.py
```

La contraseña se solicita con entrada oculta y no se guarda en `.env`. Después:

```powershell
python3.12 main.py
```
